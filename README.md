# My Bookshelf

**PDF·DOCX·HWP·HWPX·TXT 문서를 Word·한글(HWPX) 문서·Obsidian 위키 노트로 바꾸는 개인 연구 도구** — 텍스트 변환 → 챕터 분할 → (도착언어가 아닌 문서) 번역 → 문서 요약 → **EPUB·Word(.docx)·한글(.hwpx) 내보내기·Obsidian Wiki 반영(모두 가능)**을 한 흐름으로 처리합니다.

[![Windows 내려받기](https://img.shields.io/badge/Windows-Setup.exe-0078D4?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/Brightinyou/my-bookshelf/releases/latest)
[![macOS 내려받기](https://img.shields.io/badge/macOS-.dmg-000000?style=for-the-badge&logo=apple&logoColor=white)](https://github.com/Brightinyou/my-bookshelf/releases/latest)

> 🇬🇧 English manual: [README.en.md](README.en.md)

Windows와 macOS 모두 지원합니다. 같은 코어(`core/`)를 쓰고 **설치 방법만 다릅니다** — 아래 [2. 설치](#2-설치)에서 쓰시는 운영체제 부분만 보시면 됩니다.

---

## 1. 이 프로그램은 무엇인가

책이나 논문의 PDF·DOCX·HWP·HWPX·TXT를 넣으면, 다음 단계를 거쳐 **읽기 좋은 요약 위키 노트**를 만들어 Obsidian 보관함(Vault)에 저장합니다.

```
PDF/DOCX/HWP/HWPX/TXT  →  텍스트 변환  →  챕터 분할  →  번역(도착언어가 아닌 문서)  →  문서요약  →  EPUB · Word(.docx) · 한글(.hwpx) · Obsidian Wiki (모두 가능)
```

- **PDF**는 스캔본이 아닌 텍스트 레이어가 있는 것을 대상으로 합니다(스캔 PDF는 먼저 OCR 필요). **DOCX·HWP·HWPX·TXT**는 그대로 바로 처리됩니다.
- 번역·요약·위키 생성에는 **AI**를 씁니다. API 키를 넣거나, Claude/ChatGPT 구독 CLI를 켜서 사용합니다.
- 결과 노트는 **저자·핵심 요약·장별 개요·핵심 인용·핵심 키워드**를 담고, 어려운 원전은 용어 원어 병기·풀어 쓰기로 읽기 쉽게 만듭니다.

### 🪟 Windows

#### 1단계 — 내려받기

[**최신 릴리스**](https://github.com/Brightinyou/my-bookshelf/releases/latest) 페이지 아래 **Assets**에서 받습니다:

- **`Setup.exe`** — 권장. 바로 실행하면 됩니다.
- `MyBookshelf-Setup-vX.Y.Z.zip` — 브라우저가 `.exe` 내려받기를 막을 때 쓰세요. 압축을 풀면 같은 `Setup.exe`가 나옵니다.

#### 2단계 — 실행 (처음 한 번만: 보안 경고 통과 ⚠️)

`Setup.exe`를 더블클릭하면 Windows가 *"PC를 보호했습니다"* 라는 파란 창을 띄웁니다. **바이러스가 아니라 코드 서명 인증서(연 수십만 원)를 쓰지 않았기 때문**입니다.

1. 파란 창에서 **[추가 정보]** 를 누릅니다.
2. 아래에 나타나는 **[실행]** 버튼을 누릅니다.

#### 3단계 — 설치 언어 고르기

한국어 / English 중 고릅니다. 앱 화면에 쓰이는 언어이며, 나중에 **설정 탭에서 언제든 바꿀 수 있습니다.**

#### 4단계 — 파이썬 (자동)

파이썬 3.14가 없으면 설치 프로그램이 *"자동으로 받아 설치할까요?"* 라고 묻습니다. **[예]** 를 누르면 알아서 내려받아 깝니다. 이미 3.10 이상이 깔려 있으면 이 단계는 건너뜁니다.

#### 5단계 — 첫 실행 준비 (자동)

설치 마지막에 *"Preparing Python environment"* 가 뜨고 **몇 분간 멈춘 듯 보입니다 — 정상입니다.** 필요한 패키지를 받는 중입니다(네트워크에 따라 **5~20분**).

- 설치 위치: `C:\Users\<사용자>\AppData\Local\My Bookshelf`
- 진행 기록: 그 폴더의 `install.log`
- 실행이 안 되면: 같은 폴더의 `launch-error.log`

#### 6단계 — 실행

바탕화면 또는 시작 메뉴의 **My Bookshelf** 아이콘을 누릅니다. 두 번째 실행부터는 몇 초면 창이 뜹니다.

> **업데이트**: 앱의 **설정 탭 → 업데이트 확인**으로 새 판을 받을 수 있습니다.
> 다만 **v1.2.33 이전 판을 쓰고 계셨다면 이번 한 번은 직접 받아 설치**해야 합니다(저장소가 통합되기 전 판이라 옛 주소를 보고 있습니다).

### 🍎 macOS

#### 1단계 — 내려받기

[**최신 릴리스**](https://github.com/Brightinyou/my-bookshelf/releases/latest) 페이지 아래 **Assets**에서 둘 중 하나를 받습니다:

- **`MyBookshelf-vX.Y.Z.dmg`** — 권장. 익숙한 "드래그해서 설치" 창이 열립니다.
- `MyBookshelf-vX.Y.Z-mac.zip` — 압축을 풀면 앱 파일만 나옵니다. (별도 설치 프로그램이 없는 것이 정상 — 앱 자체가 설치를 겸합니다.)

> 파일 크기가 수백 KB로 작습니다 — **정상입니다.** 파이썬 환경은 첫 실행 때 내려받습니다.

#### 2단계 — 응용 프로그램에 넣기

- **DMG로 받은 경우**: `.dmg`를 더블클릭 → 열린 창에서 **`MyBookshelf.app` 아이콘을 옆의 `Applications` 폴더로 드래그**합니다.
- **zip으로 받은 경우**: 압축을 풀고 나온 `MyBookshelf.app`을 **응용 프로그램** 폴더로 옮깁니다.

#### 3단계 — 처음 한 번만: 보안 경고 통과 ⚠️

이 앱은 **Apple 서명·공증이 없는 개인 배포**라, 처음 열 때 macOS가 *"확인되지 않은 개발자"* 경고를 띄웁니다. **바이러스가 아니라 서명 비용(연 $99)을 들이지 않았기 때문**이며, 아래 절차로 한 번만 허용하면 됩니다. (DMG로 받아도 이 단계는 동일합니다 — 서명 문제라 포장 방식과 무관합니다.)

- **먼저 시도**: 응용 프로그램 폴더의 `MyBookshelf` 아이콘을 **우클릭(또는 control-클릭) → 열기 → (경고창에서) 열기**.
- **위 방법으로 안 열리면**(최신 macOS는 우클릭 우회가 막혀 있음):
  1. 그냥 한 번 더블클릭해 경고가 뜨게 둡니다(경고는 닫아도 됨).
  2. ** 메뉴 → 시스템 설정 → 개인정보 보호 및 보안**으로 들어갑니다.
  3. 아래로 스크롤하면 *"'MyBookshelf'이(가) 차단되었습니다"* 문구와 **[확인 없이 열기]** 버튼이 있습니다. 이 버튼을 누르고 나오는 창에서 다시 **열기**.

> 한 번 허용하면 그다음부터는 **아이콘을 그냥 더블클릭**하면 됩니다.

#### 4단계 — 첫 실행 준비 (자동)

처음 실행하면 필요한 파이썬 환경과 패키지를 **자동으로 설치**합니다(네트워크 상태에 따라 **5~20분**, 창이 준비 중일 수 있음). 완료되면 네이티브 앱 창이 뜹니다. 이후 실행은 몇 초면 열립니다.

> Python 3.10 이상이 필요합니다. 없으면 [python.org](https://www.python.org/downloads/)에서 설치하세요.
> 설치가 오래 걸리거나 멈춘 것 같으면 로그를 확인하세요: `~/Library/Application Support/MyBookshelf/app.log`

## 3. 첫 설정 — AI 연결

앱의 `⚙️ 설정` 탭에서 **둘 중 하나**를 준비합니다. **AI 모델은 설정에서 한 번만 고르면** 모든 단계가 그 모델을 씁니다.

- **AI 구독(CLI)** — API 키 없이 구독으로 사용 (**권장**). 우선순위가 API 키보다 높습니다.
- **AI API 키** — Gemini / OpenAI / Anthropic 키를 직접 입력. 쓴 만큼 과금됩니다.

### 처음이신가요? — CLI 설치하기

이미 **ChatGPT Plus/Pro** 나 **Claude Pro/Max** 를 쓰고 계시다면, **추가 요금 없이** 그 구독으로 이 앱을 돌릴 수 있습니다. 둘 중 하나만 있으면 됩니다.

#### 준비물 — Node.js

두 CLI 모두 Node.js가 필요합니다. 한 번만 깔면 됩니다.

- [**Node.js 내려받기**](https://nodejs.org/) — **LTS** 라고 적힌 쪽을 받아 설치하세요.
- 설치 확인: 터미널(Windows는 **PowerShell**, macOS는 **터미널**)을 열고
  ```
  node --version
  ```
  `v20.x` 처럼 나오면 준비된 것입니다.

#### ① ChatGPT를 쓰신다면 — Codex CLI

```
npm install -g @openai/codex
codex
```

`codex` 를 처음 실행하면 브라우저가 열리며 ChatGPT 로그인을 묻습니다. 한 번만 하면 됩니다.

- 안내: [Codex CLI 문서](https://developers.openai.com/codex/cli/)

#### ② Claude를 쓰신다면 — Claude Code CLI

```
npm install -g @anthropic-ai/claude-code
claude
```

`claude` 를 처음 실행하면 브라우저가 열리며 Claude 로그인을 묻습니다. 한 번만 하면 됩니다.

- 안내: [Claude Code 설치 문서](https://docs.claude.com/en/docs/claude-code/setup)

#### 마지막 — 앱에서 켜기

설치·로그인을 마쳤으면 **My Bookshelf를 껐다 켜고**, `⚙️ 설정` 탭에서 해당 토글을 켜면 됩니다. 앱이 알아서 찾습니다.

> 잘 안 되면: 터미널에서 `codex` 또는 `claude` 를 쳤을 때 실행되는지 먼저 확인하세요.
> 그 명령이 실행되지 않으면 앱도 찾지 못합니다.

## 4. 작업 흐름 상세

상단 메뉴에서 단계를 오갑니다. 각 탭의 파일 업로드 영역은 **파일 선택 또는 끌어다 놓기(Drag & Drop)** 모두 됩니다. 폴더 열기 버튼은 접이식으로 작게 두어 실제 작업 공간이 눈에 띄도록 했습니다.

> **단계가 끝나면 팝업이 다음 작업을 묻습니다.** 예를 들어 텍스트 변환이 끝나면 *"이어서 장별로 분할할까요?"* 가 뜨고, **[예, 바로 진행]** 을 누르면 **방금 처리한 책만** 다음 단계로 자동 진행됩니다(대기 목록의 다른 책은 건드리지 않습니다). 여러 권을 한꺼번에 처리하거나 직접 고르려면 **[직접 화면에서 선택]** 으로 기존 대기 목록 화면을 쓰면 됩니다. 처리 중에는 팝업이 닫히고 진행바·중단 버튼이 보입니다.

### ① 📄 텍스트 변환
- PDF/DOCX/HWP/HWPX/TXT를 올리면 **처리 대기**에 쌓입니다.
- 항목을 골라 **[텍스트 변환 처리]** — 텍스트를 추출해 TXT로 저장합니다. 원본 문서는 보관됩니다.
- **[삭제]** 로 잘못 올린 파일을 뺄 수 있습니다.
- **논문 출처로 가져오기**: URL·DOI·arXiv 번호로 논문을 바로 받아올 수 있습니다(로그인·유료 페이지는 직접 PDF를 내려받아 업로드하세요).

### ② ✂️ 챕터 분할
- 책 TXT를 **챕터 단위 파일**로 나눠 책별 폴더에 저장합니다.
- **[분할 처리]** — 챕터로 분할. **[다음단계로 이동]** — 나눌 필요가 없으면 통째로 다음 단계로 보냅니다(도착언어가 아닌 문서→번역, 도착언어 문서→문서요약).
- 짧은 문서는 별도 '짧은 문서 확인'에서 분할/이동을 고릅니다.

### ③ 🌐 번역 (다국어 → 고른 도착언어)
- 원문 언어를 자동으로 감지합니다. 영어뿐 아니라 독일어·네덜란드어·프랑스어·스페인어·이탈리아어·포르투갈어·라틴어, 일본어·중국어·러시아어·그리스어·히브리어·아랍어를 구분해 번역 프롬프트에 함께 전달합니다.
- 언어 판단은 책 전체의 여러 챕터를 섞어 수행하므로, 첫 장의 참고문헌 때문에 한국어 번역서를 외국어로 잘못 판단하는 일을 줄입니다.
- `⚙️ 설정 → 🎯 번역 도착언어`에서 한국어·영어·일본어·중국어·독일어·프랑스어·스페인어·이탈리아어·포르투갈어·네덜란드어·러시아어 중 하나를 고릅니다. 기본값은 한국어입니다.
- 번역본뿐 아니라 **챕터 요약과 위키 노트도 같은 도착언어**로 생성됩니다. 화면 언어와는 별도 설정입니다.
- 번역 결과는 호환성을 위해 도착언어와 관계없이 `_ko.txt`로 저장됩니다. 원문·번역을 문단별로 함께 보려면 **‘영한대역’** 토글을 켜 `_bilingual.txt`도 생성할 수 있습니다.
- 도착언어를 바꿔도 기존 번역본·요약은 이전 언어로 남습니다. 새 언어로 만들려면 해당 파일을 삭제한 뒤 다시 처리하세요.
- 업로드한 TXT도 **번역 대기**에 등록되며, **[▶ 시작]** 을 눌러야 번역이 시작됩니다.

### ④ 📝 문서요약
- 챕터별 요약 노트(`_wiki.md`)를 만듭니다 — 저자·핵심 요약·개요·핵심 인용·핵심 키워드(해설 포함).
- 요약은 *"저자는 ~라고 말한다"* 식이 아니라 **내용 자체를 바로 서술**하는 문체로 작성됩니다.
- **요약 분량 조절**: 설정 탭 또는 이 탭의 접이식 **‘요약 분량 조절’** 에서 요약 본문을 **원문 대비 5~40%**(기본 15%)로 정합니다. 값이 클수록 노트가 길어지고 **출력 토큰·API 비용**이 늘어납니다(원문을 보내는 입력 토큰은 동일). 짧은 장은 최소 분량을 보장합니다.
- 업로드·대기 항목을 골라 **[▶ 시작]**.

### ⑤ 📖 출력 (EPUB 생성 · DOCX 생성 · HWPX 생성 · 위키반영)
- 탭 상단의 **네 개의 독립 토글**로 출력을 정합니다. 여러 개를 켜면 선택한 모든 형식이 생성됩니다.
  - **EPUB 전자책** *(전문 그대로, 요약 아님)*: 챕터 원문·번역본 전체를 `.epub`으로 묶어 `5_전자책(EPUB)`에 저장합니다. AI를 호출하지 않아 자간정리가 끝난 책은 즉시 생성됩니다. ⚠️ 저작권이 있는 원문 전체가 그대로 담깁니다 — **이용 권한이 있는 문서에 한해**, 본인의 개인적 사용 범위에서만 쓰세요. 어디까지 허용되는지는 나라와 그 문서를 얻은 경위에 따라 다르며, 이 기능이 제3자에게 배포·공유할 권한을 주지는 않습니다.
  - **자간정리** *(한글 원문 책 전용, 선택)*: 스캔 PDF에서 추출된 인쇄 줄바꿈을 읽기 좋은 문단으로 복원합니다. EPUB 토글을 켜면 대상 수가 표시되며, **[자간정리 먼저 실행]**으로 미리 처리할 수 있습니다. AI는 공백 처리만 판정하고 본문 글자는 변경하지 않습니다.
  - **Word 문서(DOCX)** *(요약 기반)*: 요약을 편집 가능한 `.docx`로 합쳐 `5_위키문서(DOCX)`에 저장합니다.
  - **한글 문서(HWPX)** *(요약 기반)*: 요약을 편집 가능한 `.hwpx`로 합쳐 `5_위키문서(HWPX)`에 저장합니다.
  - **옵시디언 위키** *(요약 기반)*: 요약을 Obsidian 보관함의 허브 노트와 장별 노트로 저장합니다.
  - 모두 끄면 경고가 뜹니다. 하나 이상 선택해야 합니다.
- 노트/문서 앞머리에 **저자·출판일·출판사(‘지역: 출판사’ 형식)** 가 자동으로 채워집니다(원본의 표제지·판권면에서 추출, 확인되지 않으면 비워 둠).
- 이미 반영된 책을 다시 요약했다면 팝업이 **‘교체할까요?’** 로 물어 바로 갱신합니다.
- 대기 목록에서 **[전체 선택]/[해제]** 후 **[▶ 시작]**.

## 5. 시작 · 중단 · 이어하기

챕터 분할·번역·문서요약·위키반영의 AI 작업은 **[▶ 시작]** 을 누르면 처리 화면만 남고 다른 기능·탭 이동이 **잠깁니다**(실수로 작업을 벗어나는 것 방지).

- 처리 화면에는 진행률과 항목별 결과가 표시됩니다.
- **[■ 중단]** 을 누르면 **현재 항목까지 마친 뒤** 멈추고 전체 화면이 돌아옵니다.
- 남은 작업은 대기 목록에 그대로 남아 **[▶ 시작]** 을 다시 누르면 이어서 처리됩니다.
- 대기 목록에서 **[🗑 삭제]** 로 잘못 넣은 작업을 뺄 수 있습니다.

## 6. 언어 설정과 번역 단계

`⚙️ 설정 → 언어`는 화면에 표시되는 언어(한국어/English)만 바꿉니다.

- 번역 결과의 언어는 바로 아래의 `⚙️ 설정 → 🎯 번역 도착언어`에서 따로 고릅니다. 이 선택은 번역본·챕터 요약·위키 노트에 함께 적용됩니다.
- 번역 작업을 하려면 현재는 화면 언어를 **한국어**로 두세요. English 화면에서는 번역 단계가 메뉴와 파이프라인에서 숨겨집니다.
- 이미 만든 번역본·요약은 도착언어를 바꿔도 변환되지 않습니다. 필요한 결과 파일을 지운 뒤 다시 실행하세요.

## 7. 데이터 위치

기본 데이터 폴더(설치 언어에 따라 폴더명이 한글/영문):

```
0_업로드대기/            업로드·다운로드 대기 (처리 전)
1_원본PDF/               원본 PDF 보관
2_변환TXT/               변환된 TXT (완료/ = 분할 끝난 원본 보관)
3_챕터/<책>/              챕터·번역(_ko)·대역 번역(_bilingual)·요약(_wiki.md)·전체요약이 함께 있는 작업장
5_전자책(EPUB)/          EPUB으로 내보낸 전자책 (본문 전체)
5_위키문서(DOCX)/        DOCX로 내보낸 문서 (‘DOCX 문서 생성’ 선택 시, 언어 설정과 무관하게 이 이름 고정)
5_위키문서(HWPX)/        HWPX로 내보낸 문서 (‘HWPX 문서 생성’ 선택 시, 언어 설정과 무관하게 이 이름 고정)
실패/, 로그/              실패 파일·로그
```

위키 노트는 별도 Obsidian 보관함(Vault)에 저장됩니다(`⚙️ 설정`에서 선택). EPUB·Word(.docx)·한글(.hwpx)은 각각 위 `5_전자책(EPUB)/`·`5_위키문서(DOCX)/`·`5_위키문서(HWPX)/`에 저장됩니다. 설정은 `~/.config/mybookshelf/config.json`(macOS/Linux)에 저장됩니다.

## 8. 문제 해결

- **"사용 가능한 AI가 없습니다"** — `⚙️ 설정`에서 API 키를 넣거나 CLI 구독(Claude/Codex)을 켜세요.
- **업데이트했는데 옛 화면이 보임** — 앱을 완전히 종료 후 다시 여세요(실행 중인 서버가 남아 있을 수 있습니다).
- **스캔 PDF** — 텍스트 레이어가 없는 스캔본은 먼저 OCR로 텍스트 PDF/TXT로 만든 뒤 넣으세요.
- (Windows) 설치·실행 오류는 설치 폴더의 `install.log` / `launch-error.log`를 확인하세요.
