# 번역 누락 방지 적용 기록 — 2026-09-09

초기 반영에서는 기존 UI 버전 v1.3.0을 유지했고, 후속 사용자 요청으로 v1.3.1로 올린다. 이 작업은 로컬 코드·설치본 반영이며 공개 배포나 전체 재번역은 포함하지 않는다.

## 적용

- 짧은 문장 삭제와 마지막 짧은 본문이 각주에 붙는 결함 수정.
- 번역 전용 작업 목록에 원문 해시, Unicode 위치, 분류, 제외 근거, 앞뒤 문맥을 기록.
- 번호로 시작한 블록은 독립 유지. 문장 끝의 마침표 유무만으로 각주를 본문에 병합하지 않는다.
- 각주 구조 보호와 번역 생략을 분리. 설명형·불확실한 각주는 번역하고 짧은 서지정보·식별자는 보존한다. 휴리스틱이므로 완전한 의미 판정을 보장하지 않는다.
- 알려진 책/장 제목과 일치하고 쪽 번호가 바뀌며 3회 이상 반복되는 머리글만 번역 입력에서 제외. 원문 TXT는 수정하지 않는다.
- 각주·쪽표식은 원래 순서에 둔다. 이웃 본문은 참고 문맥으로만 보내며 출력 대상과 분리한다.
- 분할 결과의 비공백 문자 순서가 원문과 다르면 원문 블록으로 되돌린다. 총 문자 수는 유지분+제외 근거분과 일치해야 한다.
- 성공 캐시는 내용·목표언어·구조·문맥·처리 버전으로 식별하며 완료 후에도 유지한다. 과거 preserved/dropped는 재판정한다. 구형 대역은 목표언어가 확인되고 새 문맥이 필요 없는 일치 원문만 재사용한다.
- PDF의 본문/각주 구분선 판정 근거를 `.layout.json`에 저장. 대체 추출 결과나 해시가 다른 원문에는 이전 구조정보를 적용하지 않는다. 기존 TXT에는 없는 정보를 소급해서 만들어내지 않는다.

## 결과 파일

번역할 때 원문 챕터 옆에 `<챕터>_<언어>.audit.json`과 `.cache.json`이 생긴다. 감사 파일에는 원문 위치·제외 근거·처리 결과가, 캐시에는 성공한 번역이 기록된다. 기존 실패 시 부분 결과 보존 및 최종 번역본 보호는 유지한다.

34개 챕터의 원본 해시는 검사 전후 동일하다. 이 수치는 실제 번역 복구량이 아니라 전처리 문자 보존 검사다. 각주 판정의 의미 정확도, 실제 모델의 번역 품질, 모든 책의 EPUB 렌더링을 보증하지 않는다. 한국어 원문을 한국어로 옮길 때는 기존 목표언어 판정에 따라 복사 경로가 사용될 수 있다.

새 회귀 검사는 짧은 문장, 구조 경계/원문 위치, 반복 머리글, 손실 분할 폴백, 캐시의 재사용·무효화, 구형 대역 호환, 재시도 프롬프트 분리, PDF 구조정보, 번역 결과의 각주 링크 연결을 검증한다. AI 응답은 모의 값이며 유료 API를 호출하지 않았다.

## 주의

기존 번역본과 EPUB은 자동으로 바뀌지 않는다. 다시 번역할 때 새 규칙이 적용된다. 병합되거나 문맥이 달라진 문단, 성공 캐시/호환 대역이 없는 문단은 다시 호출하므로 비용이 누락분만큼이라고 단정할 수 없다. 먼저 문제가 있었던 챕터 하나를 재번역해 대역과 각주를 검토하는 것이 좋다.

## 추가 보완: 문장 경계 (structure-v2)

실제 번역에서 Herzfeld 2장의 `some faculty or capacity man / possesses…`가 두 요청으로 나뉘어 어색하게 번역된 사례를 확인했다. 참고 문맥 전달만으로는 문장의 한국어 어순을 복구하지 못했다.

번역 작업 목록을 만들 때 같은 본문 구간 안의 불완전한 조각을 먼저 잇고, 약 3,000자 목표로 문장 끝에서 재분할한다. 마침표 뒤 인용 숫자·윗첨자·닫는 따옴표를 종결로 인식하며 A.I., Dr. 등의 약어에서는 자르지 않는다. 각주·쪽표식·명시적 제목은 넘어 합치지 않는다. 문장 종결이 없는 12,000자 초과 예외는 요청 크기를 제한하고 `boundary_warning`으로 기록한다. 이 예외와 쪽/각주 경계를 걸친 문장의 품질은 아직 별도 검토 대상이다.

실자료 5개 챕터의 처리 단위 수: 1→1, 5→2, 10→6, 4→4, 7→6. 동일 본문 구간의 문장 중간 분할 경계는 모두 0개이며 문자 보존 수치는 동일하다. 문제 구절은 하나의 요청에 온전히 포함된다. 실제 모델 재번역은 수행하지 않았으므로 개선된 번역 문장을 검증한 것은 아니다.

작업 목록 버전은 structure-v2, 캐시 형식은 structure-v1을 유지한다. 내용·구조·문맥이 그대로인 성공 결과는 재사용하고, 묶음이 달라진 번역만 자연스럽게 캐시 키가 달라진다. 진행 중 번역을 중단하지 않고 종료를 확인한 뒤 설치본을 반영한다.

## 실재번역 및 각주 검사

후속 요청으로 Herzfeld 2·3·5장을 Codex `gpt-5.6-sol`로 새로 번역했다. 14개 단위 전부 성공, 원문 24,229자(비공백) 전부 입력 보존. 해당 실행에는 성경 장·절 식별자는 보존하되 인용문 자체는 번역하라는 추가 지시를 적용했다. 이 추가 지시는 이번 실행용이며 앱 기본 프롬프트를 변경한 것은 아니다. 문제의 문장 연결 및 영어 성경 인용문 개선을 확인하고 번역·대역·캐시 등 18개 파일을 반영했다. 원문과 1·4장 번역은 변경하지 않았다.

각주 검사는 미통과다. 미주 1~34번의 내용은 있지만, EPUB 처리 경로는 독립 정의 1~9번만 인식한다. 이는 이전 번역본에서도 같은 결과다. 기존 inline-note 분리만 추가하는 시험도 완전하지 않았으며 저자 약력이 마지막 미주에 들어갔다. 각주가 정상 분리·연결됐다고 볼 수 없으며 EPUB을 재생성하지 않았다. 별도 각주 구조 수정은 아직 적용하지 않았다.
